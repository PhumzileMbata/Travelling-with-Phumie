# Travelling-with-Phumie
## Organisation Overview
## Name: Traveling with Phumie
Traveling with Phumie is a travel agency founded in 2025 by Phumzile Mbata who began by planning trips for family members and, eventually, for friends of friends. What started as shared spreadsheets grew into a small, personally run agency based in Secunda Mpumalanga which moved to Pretoria, South Africa, that now arranges trips to over 40 destinations worldwide.
## Mission:
To design honest, well-planned trips that match what each traveller actually wants, without hidden fees or copy-paste itineraries.
## Vision:
To become South Africa's most trusted boutique travel agency for personalised, travel.
## Target Audience:
Working professionals and young families in South Africa (aged 25-45).
## Website Goals and Objectives
The website is being built to achieve the following goals:
	Increase website traffic and online enquiries from prospective travelers.
	Generate qualified leads via the online enquiry/contact form.
	Provide clear, trustworthy information.
## Current Website Analysis
This is a new website being built for Traveling with Phumie; the agency has not previously had an online presence and has relied on word-of-mouth and phone bookings. As there is no existing website, the key weakness this project addresses: prospective clients currently have no way to browse destinations, compare packages, or make contact outside of business hours.
## Proposed Website Features and Functionality
	Homepage with the logo.
	Destinations page showcasing featured trips with descriptions and starting prices.
	Packages page comparing tiered options.
	About Us page covering company history and credibility markers 
	Contact/enquiry page with a booking-style form.
	Responsive navigation linking all sections
## Colour Scheme
A bright, tropical palette: holiday-like.
